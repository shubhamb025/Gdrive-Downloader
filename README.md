# **📥 Google Drive PDF Extractor — Chrome Extension**

*A simple extension that converts Google Drive’s PDF viewer pages into a downloadable, clean PDF.*

---

## **🚀 Installation Guide**

### **1️⃣ Clone the Repository**
```bash
git clone https://github.com/shubhamb025/gdrive_downloader.git
```
(Or download the folder manually.)

### **2️⃣ Open Chrome Extensions**
Go to:
```
chrome://extensions
```

### **3️⃣ Enable Developer Mode**
Toggle **Developer mode** in the top-right corner.

### **4️⃣ Load the Extension**
Click **Load unpacked** → choose the extension folder.

✅ Your extension is now active.  
✅ A **Download File** button will appear when viewing a PDF on Google Drive.

---

## **⚠️ Important Usage Notes**

### ✅ **1. Reload the page after opening any PDF**
Google Drive loads pages progressively; reloading ensures the extension hooks correctly.

### ✅ **2. Wait 2–4 seconds before clicking Download File**
The extension **auto-scrolls** to load every page.  
Wait briefly until all pages are detected.

### ✅ **3. Do NOT scroll manually while it loads**
Manual scrolling interferes with the page-loading mechanism.

---

## **🆘 Troubleshooting**

### ❗ **PDF incomplete or missing pages?**
→ Wait a bit longer before clicking the button  
→ Reload the page and retry  
→ Google Drive sometimes delays page rendering 

### ❗ **Button not working?**
→ Wait a bit longer before clicking the button  
→ Reload the page and retry  
→ Google Drive sometimes delays page rendering
